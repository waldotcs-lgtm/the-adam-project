# The Adam Project

Interactive viewer for Sebastian C. Adams’ Synchronological Chart of History (3rd ed. ~1878).

**Image credit:** David Rumsey Map Collection, Stanford Libraries (CC BY-NC-SA 3.0). Personal / free non-commercial use only.

Live tiles stream from the Rumsey IIIF endpoint. Chart by Sebastian C. Adams.

## Local

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765/
